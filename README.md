# cmux Windows

Windows 11 port of the core cmux workflow: workspaces, split terminal panes, agent-attention notifications, and a programmable desktop shell.

> Status: bootstrap commit. The functional Tauri/ConPTY MVP is developed on `feat/windows-mvp`.

The original cmux project is macOS-native (Swift/AppKit + GhosttyKit), so this repository is a platform port rather than a direct rebuild.
